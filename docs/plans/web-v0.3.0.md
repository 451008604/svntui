# svntui Web v0.3.0 implementation

## Global Constraints

User-approved product: local browser SVN desktop-style client; daily workflows; real usable release; macOS arm64, Linux amd64 and Windows amd64. Shared Go service/SVN/locks/SafePoint/audit implementation. No CLI/TUI regressions. Browser does not run arbitrary commands or edit arbitrary files. Loopback only, bundled offline assets, no CDN. No browser code editor, repository administration, merge wizard, automation management or password storage. Chinese UI. Meaningful real SVN tests and browser acceptance. Publish v0.3.0 only after acceptance; preserve v0.2.0.

Use Go 1.24 modern guidelines (run provided skill wrapper before Go edits). Method comments need no element prefix; concise comments mark core execution steps. No CodeGraph index exists. Agents must not spawn other agents or commit another agent's files. All dependencies/build outputs must stay reproducible. Reports go into this plan's .superpowers/sdd workspace.

## Shared HTTP contract

JSON envelope: {ok:boolean,data:any,error:null|{code:string,message:string},exit_code:number}. Fields snake_case. No shell command strings accepted. API prefix /api/v1. Project identifiers are opaque IDs derived from canonical WC root, not user-supplied filesystem paths except explicit project registration. Typed HTTP DTOs, not TUI table strings. Error HTTP codes reflect argument/auth/conflict/not-found/server errors; SVN classification preserved.

Session: POST /session {token} exchanges a single-use startup token for an HttpOnly SameSite=Strict cookie and returns {csrf_token,version}; GET /session retrieves same state for an authenticated browser. Origin and Host must match actual loopback listener. Mutations require X-CSRF-Token; bootstrap instead requires the startup token and matching origin. Never place startup secrets in logs or query URLs; browser uses URL fragment and removes it immediately.

Projects: GET /projects -> [{id,name,path,modified,conflicts,unversioned,error?}]; POST /projects {path,name?} -> project; DELETE /projects/{id}. Existing config projects/recent shared. Removing a project never deletes its WC. Registration validates SVN root and canonicalizes real path.

Workspace: GET /projects/{id}/status?remote=1 -> {entries:[{path,item,props,repos_item,repos_props,changelist,tree_conflicted,revision}],url,root,revision}; GET /projects/{id}/diff?target=... (repeatable) -> {text}. Non-versioned previews reuse existing service. Bound outputs retain explicit truncation errors, never silent success. Paths must be contained after symlink resolution; allow safe deletion/inspection of symlink itself but never traversal outside project. No .svn file access via file/preview routes.

History: GET /projects/{id}/history?target=&before_revision=&limit=&author=&search=&since=&until= -> {entries:[{revision,author,date,message,paths:[{action,path,copy_from_path?,copy_from_revision?}]}],next_revision,has_more}; GET /projects/{id}/history/{revision}/diff?target= -> {text}. Use current shared history semantics and filters, no new revision guessing.

Conflicts: GET /projects/{id}/conflicts -> [{path,kinds:[text|property|tree],base,mine,theirs,detail,accepts:[working|mine-full|theirs-full|base]}]. Size-limited artifacts, unavailable/binary explanations. Reuse service resolving and conflict marker protections; property/tree supported options restricted by real SVN type. No automatic resolved after external editor exit.

Draft: GET/PUT /projects/{id}/draft, body/data {targets:[],message:string}. Atomic local JSON under StateDir/web, canonical project + repository identity bound; survives reload, random port and server restart. Successful commit clears draft, failure preserves; UI debounce saves and shows save failures. Refresh selected paths against current status without silently selecting new paths.

Previews: POST /projects/{id}/previews {action,targets:[],message?,changelist?,new_path?,revision?,accept?,remove?,safepoint_id?} -> {id,action,targets,summary,output,risk:normal|high,expires_at}. Actions allowlist commit/add/delete/move/revert/update/changelist/resolve/cleanup/restore. Commit requires targets or explicit changelist expanded server-side, no unselected recursive children. Update preview calls existing update dry-run. Restore preview validates scoped SafePoint. Freeze normalized request and fingerprint affected WC contents/properties/SVN state; expiry ten minutes.

Execution: POST /projects/{id}/operations {preview_id,confirm:true,confirmation?:"YES"} -> job. High risk delete/revert/restore require YES. Revalidate preview before execution, stale returns 409 and requires re-preview. Duplicate execution of one preview returns same job, never another write. One active write per WC; use existing cross-process lock too, busy returns 409; no automatic write retries. Jobs use process-owned context independent of HTTP connection. Result success/failure always refreshes actual SVN status. Returned job shape {id,project_id,action,state:running|succeeded|failed,summary,output,error?,started_at,finished_at?,safepoint_id?}. GET /jobs and GET /jobs/{id}; GET /events emits SSE event 'job' with full job on changes plus keepalive; reconnect fetches snapshots. Bound finished job history (100), output 1 MiB per job. Reads honor request cancellation and bounded concurrency. No fake percentages or stdout streaming claim.

SafePoints: GET /projects/{id}/safepoints -> scoped list [{id,created_at,reason}]; GET /projects/{id}/safepoints/{sid} -> scoped manifest; restore uses preview/execute with existing protection. Do not expose snapshots of unrelated WCs. GET /projects/{id}/operations -> existing bounded audit tail, sanitized; do not invent durable jobs. On restart show actual WC state and historical audit, never replay writes.
