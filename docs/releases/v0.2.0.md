# svntui v0.2.0

中文 SVN 终端客户端，同时提供交互界面和脚本命令。直接调用系统 SVN，使用现有工作副本与 SVN 认证配置。

## 下载与安装

| 平台 | 安装包 |
| --- | --- |
| macOS Apple 芯片（arm64） | [svntui-v0.2.0-macos-arm64.tar.gz](https://github.com/451008604/svntui/releases/download/v0.2.0/svntui-v0.2.0-macos-arm64.tar.gz) |
| Linux Intel/AMD 64 位（amd64） | [svntui-v0.2.0-linux-amd64.tar.gz](https://github.com/451008604/svntui/releases/download/v0.2.0/svntui-v0.2.0-linux-amd64.tar.gz) |
| Windows Intel/AMD 64 位（amd64） | [svntui-v0.2.0-windows-amd64.zip](https://github.com/451008604/svntui/releases/download/v0.2.0/svntui-v0.2.0-windows-amd64.zip) |

1. 安装系统 SVN，并确认 `svn --version --quiet` 能运行。
2. 下载对应安装包和 [SHA256SUMS.txt](https://github.com/451008604/svntui/releases/download/v0.2.0/SHA256SUMS.txt)，校验后解压，将程序目录加入 PATH。
3. 运行 `svntui --help`，然后在 SVN 工作副本根目录运行 `svntui`；也可以指定路径：`svntui "/path/to/working-copy"`，Windows 为 `svntui "C:\work\project"`。

无需安装 Go。各安装包包含 MIT 许可证和离线文档。完整步骤：**[安装指南](https://github.com/451008604/svntui/blob/v0.2.0/docs/installation.md)** · **[使用与工作流指南](https://github.com/451008604/svntui/blob/v0.2.0/docs/workflows.md)**。

## 主要功能与修复

- 独立提交页：选择文件、查看差异、多行说明和外部编辑器；取消或失败后保留当前会话草稿。
- 原生 SVN changelist、按路径/状态/分组筛选、多项目收藏与切换。
- 仓库逐级浏览，历史分页和作者/日期/说明检索，blame 与任意两修订比较。
- 合并修订选择、预演与确认，文本/属性/树冲突分类处理和外部工具复查。
- 工作副本写操作 CLI、统一 JSON 与退出码，属性与 externals、指定修订/稀疏更新、补丁导入导出。
- 修复特殊 `@` 文件名目标歧义、changelist 状态遗漏、多选属性错误目标、远端纯属性变化和已删除文件历史等问题。
- SafePoint v4 保护目录恢复时新增的未版本化/忽略文件，支持二进制和替换节点恢复；不完整保护会在写入前中止。
- 操作日志轮转、近期记录按文件尾读取，以及大命令输出的内存限制。
- 修复 Windows 控制台环境下的中文路径操作，并验证终端模式、中文多行输入和外部编辑器返回流程。

## 常用操作

在 TUI 中，`d` 查看差异，`Space` 选择文件，`C` 进入提交页，`Ctrl-S` 确认，`?` 查看帮助，`q` 退出。

在工作副本根目录使用 CLI：

```bash
svntui status --path . --remote --json
svntui update --path .
svntui update --path . --apply --yes
svntui commit --path . --message "fix: update message" --yes src/main.go
svntui history log --path . --page --limit 50
```

请替换示例文件名。选项放在位置参数之前。`update`、`merge`、`patch apply` 默认预演，实际写入需 `--apply --yes`；提交必须明确选择目标文件或 changelist。

## 验收与已知边界

2026-10-18 已完成该版本源代码的 macOS、Linux、Windows 实机验收：macOS 竞态测试与 39 项终端检查；Linux 171 项顶层测试、48 项 CLI 和 32 项终端检查；Windows 166 项顶层测试、80 项终端检查。Windows 另有 6 项测试因符号链接权限或 Unix FIFO 能力不适用而跳过。终端流程覆盖中文路径、多行输入、选定文件提交、窗口缩放和外部编辑器。

本次 Release 复用上述验收通过的三个二进制文件，补充文档后重新封装；程序二进制哈希与验收版本一致。

- macOS 包适用于 Apple 芯片；本次未提供 Intel Mac、Linux ARM64 或 Windows ARM64 原生包。
- 程序未做发行者代码签名或 macOS 公证；受设备应用运行策略限制时，请遵循设备要求。
- SafePoint 使用 v4 清单，旧清单保留供查看和手工提取，拒绝自动恢复；未解决冲突不能创建可恢复快照。
- 提交草稿仅在当前会话保留；普通文本补丁不包含二进制内容；复制/移动恢复为等价路径与内容变更。
